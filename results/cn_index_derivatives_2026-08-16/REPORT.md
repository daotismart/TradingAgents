## 1. 结论摘要

1. **Yahoo Finance 默认数据链无法直接交易/定价中金所股指期货与期权**：`IF=F` / `IH=F` / `IC=F` / `IM=F` 全部无行情，期权链为空。要用 TradingAgents 分析这些品种，需走国内数据源（本测试使用 akshare）或映射到 ETF 代理标的。
2. **近 20 个交易日风格显著偏小盘**：IM（中证1000）期货 +8.28%，IC（中证500）+6.39%，IF/IH 约 +3.3%。波动同步放大，IM/IC 年化波动约 40%+。
3. **期现结构统一贴水**：四大品种基差均为负，贴水约 **90–160 bp**（IF/IH 约 -90 bp，IC/IM 约 -150 bp），符合套保需求主导下的常态贴水。
4. **隐含波动偏温和且回落**：50ETF QVIX 收 16.47，300ETF QVIX 收 18.04，近 5 日分别下行约 0.7 / 1.5 个点。
5. **交易倾向（研究口径）**：
   - 短线不宜追涨 IM/IC（已强势放量后持仓连续下降）；
   - IF 相对稳健，贴水提供一定期现收敛缓冲，更适合作为指数对冲/中性腿；
   - IO/MO 近月虚值看跌相对虚值看涨更贵（偏度偏高），保护性买权成本不低，偏多策略更宜卖偏/买宽跨需谨慎。

## 6. 情景化交易测试思路（非实盘指令）

### 6.1 指数期货

| 策略假设 | 逻辑 | 主要风险 |
| --- | --- | --- |
| IF 空头套保 / 对冲股票多头 | 贴水约 -100bp，大盘波动低于小盘 | 若风格切回大盘，IF 相对升水修复与价格上行 |
| 避免追多 IM/IC | 20 日涨幅与波动双高，持仓下降 | 若流动性驱动延续，空头/观望踏空 |
| IC/IM vs IF 多空价差（已拥挤后减仓） | 小盘相对强势或已部分定价 | 政策/权重再平衡导致风格骤然切换 |

### 6.2 股指期权

| 策略假设 | 逻辑 | 主要风险 |
| --- | --- | --- |
| IO 备兑 / 弱买认购 | IV 回落 + ATM call/put 接近平价 | 突发上行挤压 |
| MO 买保护性 put 成本偏高 | skew 3.7，保险贵 | 若改为卖 put 则暴露缺口风险 |
| 日历价差（近卖远买波动） | 近月 IV 回落、远月列表完整 | 期限结构倒挂或跳空 |

## 7. 对 TradingAgents 产品化建议

1. **数据层**：为 A 股衍生品增加可选 vendor（akshare/本地 CSV），不要默认 Yahoo。
2. **标的识别**：区分 `futures` / `options` / `etf_proxy`，避免基本面分析师对期货合约编造“公司财报”。
3. **报告模板**：股指衍生品报告应强制输出基差、持仓、QVIX、P/C、近月偏度，而非股票式 PE/PS。
4. **风控提示**：股指期货有保证金与强制减仓规则；期权有权利金损耗与流动性（远月/深度虚值）约束。
